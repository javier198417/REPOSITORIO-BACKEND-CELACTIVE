CelActive Services 📱🔧
Sistema completo de gestión y servicios técnicos para talleres de reparación de dispositivos móviles, compuesto por un backend robusto en Flask (Python) y una aplicación móvil multiplataforma desarrollada en Flutter (Dart).

🛠️ Tecnologías y Arquitectura
Frontend: Flutter, Dart, Material Design, Paquete http.

Backend: Python, Flask, Flask-SQLAlchemy, Flask-CORS, Flask-Caching, Flask-HTTPAuth.

Procesamiento Asíncrono: Celery (con SQLite como broker/backend de tareas).

Base de Datos: MySQL (gestionado mediante phpMyAdmin).

Proyecto: CelActive Services
Aplicación móvil en Flutter conectada a un backend en Flask + MySQL, que permite login de clientes y gestión de servicios.

Fundamentación técnica
Framework: Flutter → multiplataforma, rendimiento nativo.

Backend: Flask → ligero, flexible y fácil de integrar con MySQL.

Destino de ejecución: Emulador y celular físico → pruebas reales y demostración.

Direccionamiento: IP LAN configurada (0.0.0.0 en Flask, IP local en Flutter).
